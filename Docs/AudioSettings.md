# 소리 설정

- 타이틀의 설정 버튼 또는 대국 상단의 소리 설정 버튼으로 엽니다.
- 배경음악과 돌 놓기 효과음을 0~100%로 독립 조절하며 즉시 적용합니다. 0%는 음소거입니다.
- 효과음 듣기로 현재 볼륨의 착수음을 미리 들어볼 수 있습니다.
- 닫기, 배경 클릭, Esc로 닫으며 PlayerPrefs에 저장합니다. 설정창에서 대국 입력은 차단하지만 온라인 대국의 시간은 멈추지 않습니다.
- GameAudio는 씬 전환 동안 유지되어 음악을 중복 재생하지 않습니다. 네트워크로 확정된 상대 착수도 효과음을 냅니다.
- 현재 음원은 코드에서 생성하는 짧은 타격음과 잔잔한 오리지널 반복 멜로디입니다. 외부 음원·추가 패키지는 필요 없습니다.

검증: Unity 컴파일 성공. Play Mode에서 두 슬라이더, AudioSource 즉시 반영, 음소거, 미리 듣기, 저장 및 다시 열기 확인. Console 오류 없음. 네트워크 2인 실제 청음과 재실행 후 복원은 별도 실행하지 않았습니다.
