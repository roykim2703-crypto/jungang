# 타이틀 튜토리얼 수정

1. `Assets/Scenes/Home.unity`를 열고 Hierarchy의 `Canvas`를 선택합니다.
2. Inspector의 **Home Tutorial → Tutorial Pages** 목록에서 장면을 추가하거나 순서를 바꿉니다. 목록의 순서가 이전/다음 버튼의 순서입니다.
3. 각 장면의 **Cutscenes**는 화면에 표시할 Sprite 이미지 목록입니다. **Title**과 **Description**은 편집용 메모로 보존되며 화면에는 표시하지 않습니다. 새 이미지는 Texture Type을 Sprite (2D and UI)로 설정해서 넣습니다.
4. 컷씬 한 장은 고정됩니다. 여러 장은 목록 순서대로 반복합니다. 빈 항목은 건너뛰고, 이미지가 없으면 위쪽은 빈 배경으로 표시됩니다.
5. **Cutscene Interval**은 각 컷씬을 보여 주는 시간(기본 3초), **White Fade Duration**은 흰색으로 덮는 시간과 다시 걷어내는 시간(각각 기본 0.4초)입니다. 설명은 컷씬이 바뀌어도 유지됩니다.
6. 별도 프레임·제목·설명·닫기 버튼 없이 튜토리얼 이미지 자체만 원본 비율로 표시합니다. Frame Image와 Font는 기존 직렬화 데이터 호환을 위해 보존되며 표시에는 사용하지 않습니다.

타이틀의 게임 방법 버튼으로 열고, 이미지 좌우의 화살표 버튼 또는 키보드 좌우 화살표로 장면을 넘깁니다. 첫/마지막 장에서는 해당 방향 버튼이 숨겨집니다. 이미지 바깥 어두운 영역 클릭 또는 Esc로 닫습니다. 이미지와 화살표 클릭은 바깥 클릭으로 처리하지 않습니다. 다시 열면 첫 장면부터 시작합니다. 다른 장면으로 이동하거나 닫으면 이전 컷씬 재생을 중단합니다.

현재 튜토리얼은 같은 목재 프레임·돌·픽셀 글씨 스타일의 3장으로 구성됩니다.

1. **기본 착수와 육목 승리** — `Assets/Image/타이틀 화면/기본 착수와 육목-픽셀.png`: 빈 교차점에 번갈아 착수, 가로·세로·대각선 육목 승리.
2. **증강 사용 후 착수 규칙** — `Assets/Image/타이틀 화면/증강 착수 규칙-픽셀.png`: 제공된 대화 기반 55·44 및 확정 승리 수 금지, 한쪽 막힌 5와 단일 4 허용.
3. **증강 카드 선택과 사용** — `Assets/Image/타이틀 화면/증강 카드 사용-픽셀.png`: 3장 중 1장 선택, 내 차례에 최대 1장 사용, 이후 착수 제한 확인. 카드 그림은 사용 흐름을 설명하는 예시입니다.

각 페이지는 고정 이미지 1장입니다. 이전의 첫 장면용 컷씬 원본은 삭제하지 않았습니다. Play Mode에서 편집한 값은 재생 종료 시 돌아가므로 영구 편집은 재생을 멈춘 상태에서 하세요.

이미지 제작: 내장 image_gen 사용. 공통 프롬프트는 기존 증강 규칙 이미지를 스타일 참조로 하여 짙은 목재 프레임, 꿀빛 바둑판, 흑백 픽셀 돌, 금빛 제목과 양피지 표제를 유지하도록 지정했습니다. 기본 장면은 번갈아 착수와 정확히 6개 돌의 승리 예시, 카드 장면은 3장 중 선택 → 내 차례 사용 → 돌 놓기 흐름을 요청했습니다. 실제 게임 로직은 변경하지 않았습니다.
