# 타이틀 튜토리얼 수정

1. `Assets/Scenes/Home.unity`를 열고 Hierarchy의 `Canvas`를 선택합니다.
2. Inspector의 **Home Tutorial → Tutorial Pages** 목록에서 장면을 추가하거나 순서를 바꿉니다. 목록의 순서가 이전/다음 버튼의 순서입니다.
3. 각 장면의 **Title**은 장면 제목, **Description**은 프레임 아래 설명, **Cutscenes**는 프레임 위쪽에 표시할 Sprite 이미지 목록입니다. 새 이미지는 Texture Type을 Sprite (2D and UI)로 설정해서 넣습니다.
4. 컷씬 한 장은 고정됩니다. 여러 장은 목록 순서대로 반복합니다. 빈 항목은 건너뛰고, 이미지가 없으면 위쪽은 빈 배경으로 표시됩니다.
5. **Cutscene Interval**은 각 컷씬을 보여 주는 시간(기본 3초), **White Fade Duration**은 흰색으로 덮는 시간과 다시 걷어내는 시간(각각 기본 0.4초)입니다. 설명은 컷씬이 바뀌어도 유지됩니다.
6. **Frame Image**에서 프레임 텍스처를 교체할 수 있습니다. 화면 영역은 현재 제공된 3:2 프레임의 위쪽 구멍과 아래 설명란에 맞춰져 있습니다.

타이틀의 게임 방법 버튼으로 열고, 이전/다음 버튼 또는 좌우 화살표로 장면을 넘깁니다. 닫기 버튼 또는 Esc로 닫습니다. 다시 열면 첫 장면부터 시작합니다. 다른 장면으로 이동하거나 닫으면 이전 컷씬 재생을 중단합니다.

제공된 두 장면은 기존 오목판/증강 예시 이미지를 이용한 편집용 예시이므로 실제 튜토리얼 내용으로 교체하세요. Play Mode에서 편집한 값은 재생 종료 시 돌아가므로 영구 편집은 재생을 멈춘 상태에서 하세요.
